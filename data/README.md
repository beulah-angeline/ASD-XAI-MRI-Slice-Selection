# Dataset

This project uses structural MRI data from the **Autism Brain Imaging Data Exchange (ABIDE)** dataset.

The raw MRI data is **not included in this repository**. Users should obtain the dataset through the appropriate ABIDE data-sharing resources and organize the files according to the preprocessing requirements in the project notebooks.

The validation experiments reported in this repository use data from **6 subjects**:

* 3 ASD subjects
* 3 Control subjects
* 1,054 validation MRI slices in total

Please refer to the project notebooks for the preprocessing and data preparation steps.
