# Trained Models

This directory is reserved for trained deep learning model files used in the experiments.

The trained model weights are **not included in this repository**. The notebooks contain the model architecture, training, evaluation, and explainability workflow used in the project.

The main deep learning models evaluated during the experiments include:

* EfficientNetB0
* ResNet50
* SqueezeNet

The final XAI-guided slice selection approach uses **SqueezeNet with Integrated Gradients**.
